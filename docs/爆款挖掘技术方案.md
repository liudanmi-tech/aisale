# 爆款挖掘技术方案（v1 草案）

目标：把爆款库从样例数据换成真实数据，每天从 TikTok、X（以及 Facebook）抓取竞品与同类目的**爆款**和**精品**视频，自动拆解结构、打分，经人工审核后进入爆款库，供 Agent 洗剧本。

试点范围不变：尼日利亚、巴基斯坦，单品牌。

---

## 1. 先说结论

1. **竞品广告的真实点击率、完播率拿不到。** 任何平台都不会公开别人的广告数据。我们能拿到的是代理信号：投了多少天、开了多少个变体、估算的曝光/花费、点赞评论分享，以及 TikTok 官方 Top Ads 给的点击率**分位**（如「前 5%」）。所以竞品数据全部标「估」。
2. **真正准的数据只有传音自己的投放历史。** 用已有的 TikTok 广告权限拉自家历史素材的真实 CTR、2 秒/6 秒播放率、完播率、转化率。它有两个用处：一是作为最可信的爆款来源，二是用来**校准**竞品打分公式（见第 4.4 节）。
3. **数据来源按「官方 → 采购 → 自建抓取」排优先级。** 能用官方接口或采购数据的，不自己爬。自建抓取只做公开页面（不登录），用浏览器 Agent 低频访问。
4. **分两个榜：** 「爆款」看规模（投放久、量大、播放高），「精品」看效率（规模不一定大，但钩子强、互动率和分享率高）。洗剧本时两者都要用。

## 3. 采集流水线

```
定时调度（每市场每天 1 次，当地凌晨）
  → 采集适配器（每个来源一个，统一输出格式）
  → 原始层：原样保存接口返回 + 指标快照（带时间戳）
  → 下载视频到 R2（仅内部分析用）
  → 去重聚类：同一素材的多次投放 / 搬运合并成一组，组内条数 = 变体数
  → 结构拆解：多模态模型看视频，输出钩子、分镜、卖点、语言、人物、音乐、CTA
  → 打分：爆款分、精品分、可信度
  → 待审核队列 → 人工通过 → 进入爆款库，可用于洗剧本
```

要点：

- **快照是关键。** 同一条视频每天记一次播放/点赞/分享（广告则记是否还在投），连续几天的变化才能算增速、投放天数和疲劳。新发现的视频前 3 天每天快照，之后每周一次，30 天后停止。
- **去重：** 用视频画面指纹加文案相似度判断「同一素材」。竞品把同一素材剪成多个版本反复投，说明它在放量，这个「变体数」是最强的爆款信号之一。
- **结构拆解（DNA）：** 用 OpenRouter 上支持视频理解的模型（如 Gemini 2.5 Pro）。输出写进爆款库已有的 `dna` 字段，洗剧本直接用：
  - 前 3 秒钩子类型（对比、痛点、悬念、反转、真人测评……）
  - 逐镜头：时长、画面、字幕、口播
  - 主打卖点、出现的机型、本地化元素（语言、场景、服装）
  - 音乐风格、CTA 形式
- **适配器接口统一。** 方便以后加 Kwai、YouTube Shorts 等来源：

```python
class SourceAdapter:
    name: str                      # creative_center / own_history / x / vendor_xxx ...
    def discover(self, market, query) -> list[RawItem]: ...    # 找新素材
    def snapshot(self, item) -> MetricSnapshot: ...            # 更新指标
    def download(self, item) -> str | None: ...                # 返回视频文件，拿不到就 None
```

## 4. 怎么判定爆款和精品

### 4.1 原则

- **同组内比较。** 按「市场 × 平台 × 广告/自然流量」分组，在近 30 天的同组素材里算百分位。尼日利亚 TikTok 的 50 万播放和巴基斯坦 X 的 5 万浏览不能直接比。
- **看相对值，不只看绝对值。** 自然流量最重要的是「爆款倍数」：这条视频的播放量 ÷ 该账号最近 30 条视频播放量的中位数。大号发什么都有量，小号突然爆了才说明内容本身强。
- **规模和效率分开打分**，分别对应「爆款」和「精品」。

### 4.2 信号

**广告（来源 1、2、3、6）**

| 信号 | 含义 | 为什么有用 |
| --- | --- | --- |
| 持续投放天数 | 第一次发现到最后一次还在投 | 广告主不会长期给亏钱的素材花钱，投得越久越可能赚钱 |
| 变体数 | 同一素材被剪成多少版本在投 | 在放量 |
| 估算曝光 / 花费 | 第三方估算 | 规模 |
| 点击率分位、6 秒播放率 | Creative Center 官方给的 | 最接近真实效果的公开数据 |
| 互动率 | (点赞+评论+分享) ÷ 播放 | 内容吸引力 |

**自然流量（来源 4、5）**

| 信号 | 计算 | 为什么有用 |
| --- | --- | --- |
| 爆款倍数 | 播放 ÷ 账号近 30 条中位数 | 内容本身强不强 |
| 播放量 | 原值 | 规模 |
| 分享率 | 分享 ÷ 播放 | 最强的内容信号，愿意转给别人 |
| 增速 | 发布后 48 小时播放增长 | 识别正在起量的视频 |
| 购买意向评论占比 | 评论里问价格、问哪里买、问型号的比例（模型判断） | 和转化最相关 |

### 4.3 打分公式（初始权重，后面用传音数据校准）

每个信号先转成组内百分位（0–100），再加权：

- **广告爆款分** = 0.30 投放天数 + 0.20 变体数 + 0.25 估算曝光 + 0.15 点击率分位 + 0.10 互动率
- **自然流量爆款分** = 0.35 爆款倍数 + 0.25 播放量 + 0.20 分享率 + 0.10 增速 + 0.10 购买意向评论
- **精品分**（不看规模）= 0.35 点击率分位或 6 秒播放率（没有则用分享率）+ 0.30 互动率 + 0.20 购买意向评论 + 0.15 钩子强度（模型按前 3 秒打分）

缺失的信号不算 0，而是把它的权重按比例分给其他信号，同时降低**可信度**。

**入库门槛：**

- 爆款：爆款分 ≥ 85，且广告已投 ≥ 7 天或自然流量播放 ≥ 市场门槛（尼日利亚、巴基斯坦先定 10 万，按实际数据调整）。
- 精品：精品分 ≥ 85，且爆款倍数 ≥ 3（自然流量）或已投 ≥ 3 天（广告）。
- 发布不足 72 小时的进「观察列表」，满 3 天再判。
- 每条都记录**可信度**（高 / 中 / 低）：传音自有数据为高；有官方分位为中高；纯估算为中或低。页面上展示，估算值继续标「估」。

### 4.4 用传音自己的数据校准

公开信号到底能不能预测效果，用传音自家素材来检验：

1. 对传音历史素材，只用**公开能拿到的信号**（播放、点赞、分享、投放天数等）算一遍爆款分。
2. 和它们的**真实** CTR、完播率、转化率比较排名一致性（Spearman 相关系数）。
3. 调整权重，让排名一致性最高。目标相关系数 ≥ 0.4，达不到说明某些信号没用，需要换信号。
4. 上线后形成闭环：用某条爆款洗出来的剧本投放后，把真实效果记回这条爆款上。哪个来源、哪类钩子洗出来的效果好，权重就自动上调。

### 4.5 账号公开数据 × 第三方估算：交叉评估

竞品在 TikTok、X 的广告分两种：

| 类型 | 账号主页可见 | 公开数据 |
| --- | --- | --- |
| 加热帖（TikTok Spark Ads、X 推广帖、达人「付费合作」帖） | 是 | 播放/浏览、点赞、评论、分享是真实数字，且包含付费带来的播放 |
| 纯广告（非 Spark 广告、X 仅推广帖） | 否 | 播放不公开，只能靠第三方在信息流里观测、估算 |

做法：

1. **按账号清单每日快照。** 竞品在两个市场的官方账号、常合作的本地达人、传音自家账号（对照）。TikTok 用第三方数据接口；X 用官方 API 按账号拉帖子（约 30 个账号 × 每天 20 条 ≈ $90/月，以官方价格为准）。
2. **对上号。** 用画面指纹把同一视频在「账号公开数据」和「第三方情报」里认成同一条。
3. **识别是否在投放。** 播放远高于账号近 30 条中位数，同时点赞率明显低于账号平时水平，判为「疑似加热」；第三方也观测到在投则确认。
4. **校准第三方估算。** 两边都有数据的帖子，算「公开播放 ÷ 第三方估算曝光」，按市场 × 平台 × 供应商取中位数作为校正系数，乘到只有第三方数据的纯广告上。
5. **综合打分：** 规模 30%（公开播放，没有则用校准后的第三方曝光）+ 持续投放 25%（天数、变体数）+ 内容效率 25%（互动率、分享率、播放倍数）+ 购买意向 20%（评论）。
6. **可信度：** 两边都有为高；只有公开数据为中（花费未知）；只有第三方为中低，标「估」。

注意：加热帖的播放含付费部分，不能只看播放，要结合互动率、分享率；评论需过滤重复、无意义内容以防刷量；点击率、完播率仍拿不到，最终选素材靠自家小预算测试投放。

## 6. 合规与风险

- **优先官方和采购数据。** TikTok、X、Meta 的用户协议都限制自动抓取，自建抓取有封号和法律风险。自建只抓公开页面，不登录、不绕过验证、低频访问；账号和 IP 与传音正式投放账户完全隔离。
- **视频只做内部分析。** 下载的竞品视频存在私有存储里，不对外发布。洗剧本只借用结构和节奏（钩子类型、分镜节奏），不复用别人的画面、音乐和人物。
- **不存个人信息。** 评论只保留文本用于判断购买意向，不存评论者账号。
- **人工审核兜底。** 进入爆款库前必须人工通过，审核时可以剔除不合适的内容（敏感话题、侵权风险）。
